THIS PAGE EXISTS SO THE ROBOTS TEST IS NOT VACUOUS. It is linked from the navigation on every page of this fixture site, so a crawler that ignores robots.txt WILL reach it; robots.txt disallows /private, so a crawler that honours robots.txt will not. A test asserting "no fetched page is under /private" against a site with no such page passes for the wrong reason, which is the failure this file exists to prevent.

Supplier price lists, engineer rotas and the trade account number would live here on a real site - which is the ordinary reason a small business disallows a path rather than deleting it.
