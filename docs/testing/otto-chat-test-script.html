Testing Otto's chat

Twenty checks of what Otto is built to do and to refuse. Type each one into the chat, compare what comes back with the pass line, and mark it. Your marks and notes stay in this browser.

Before you start

  1. Sign in as a merchant, not as admin@ppcway.com. PPCWay's staff own no business, so the staff account has no chat. Use a business whose Google Ads account is connected and has synced: its dashboard shows figures.
  2. Check Otto is switched on. In the internal console, Settings should show Otto can talk: On and Chat is screened: On. If Otto cannot talk, every question answers: Otto is not switched on in this deployment yet.
  3. Open the chat at app.ppcway.com/chat, and keep the dashboard open in another tab to compare figures.
  4. Press “Start again” between tests so each one starts from a fresh conversation. Otto now remembers the questions before it, which F1 relies on and the others should not.
  5. What it costs: each question counts toward the business's monthly allowance (100 a month on Starter, a provisional figure) and a few cents of model spend. Question C1 may leave one proposal in the inbox. It waits for approval, and with Google Ads writes off it cannot reach Google either way.

Fixed on 4 November, and worth checking

  • Otto now remembers the conversation. Each question carries the ones before it, up to the last six, for as long as the chat stays open. Start again at the top of the chat, or leaving the page, begins a new one. Test F1 checks it.
  • Each kind of block has its own sentence. A card number is told about personal details; an attempted instruction to Otto is told it reads like one; an unsafe link is named. Tests D3 and D4 check two of them.
